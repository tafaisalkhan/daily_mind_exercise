# Publish the Math Mind privacy policy

1. Replace the Contact placeholder in `privacy-policy.html` with a public support email.
2. Commit this `docs` folder to a GitHub repository.
3. Open **GitHub repository → Settings → Pages**.
4. Select **Deploy from a branch**, then choose the main branch and `/docs`.
5. Put the resulting URL in **Google Play Console → App content → Privacy policy**.

Typical URL: `https://USERNAME.github.io/REPOSITORY/privacy-policy.html`

The published wording must be updated to match the final ads, analytics, billing, notifications, accounts, and data collection used by the release build.
