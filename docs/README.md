# Publish the Daily Mind Excersize privacy policy

1. Commit this `docs` folder to a GitHub repository.
2. Open **GitHub repository → Settings → Pages**.
3. Select **Deploy from a branch**, then choose the main branch and `/docs`.
4. Put the resulting URL in **Google Play Console → App content → Privacy policy**.

Typical URL: `https://USERNAME.github.io/REPOSITORY/privacy-policy.html`

The published wording must be updated to match the final ads, analytics, billing, notifications, accounts, and data collection used by the release build.
